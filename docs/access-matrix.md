## Політика HTTP-відмов

- Анонім → `401` Problem Details без HTML redirect (подія `OnRedirectToLogin` з ЛР 3).
- Authenticated non-owner (Reporter) для чужого інциденту → **`404` Problem Details «Інцидент не знайдено»**,
  така сама відповідь, як для неіснуючого id (відрізняється лише `traceId`).

Обґрунтування вибору 404: Reporter не має права навіть знати, що інцидент з таким id існує.
Відповідь 403 підтвердила б існування чужого ресурсу і дозволила б перебором з'ясовувати наявні id.
Обидві гілки (чужий і неіснуючий) формує один helper `IncidentNotFound()`, а detail не містить id.

Роль Analyst дає лише читання details для аналізу; права довільно змінювати чужий content з неї не випливає.
Роль Administrator не отримує невизначених предметним правилом дозволів і не обходить ownership.
